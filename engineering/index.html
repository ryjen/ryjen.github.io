Selected case studies

Configuration as a reviewed state transition — Config Drift Guard

An independent internal-platform vertical slice, not a deployed enterprise control plane. The important decision was to separate observed configuration, immutable proposed remediation, approval, mutation, and verification. Fastify, SQLite and a Next.js operator UI make the run observable; stale-plan checks prevent approval of a changed state.

Source, five-minute demo and failure scenarios

Mobile authority without a mandatory backend — Eyespie

An independent, closed-alpha Kotlin Multiplatform application. The Wayfinder implementation uses SQLDelight for authoritative local state, native CameraX/AVFoundation boundaries, MediaPipe embeddings and signed versioned .eyespie game interchange. The former Supabase design is historical.

Android automation and selected signed-artifact checks exist, but cross-device physical acceptance, iOS signed distribution, and the final closed-alpha release gate remain outstanding.

Source, architecture and candidate-bound acceptance criteria

Reversible filesystem changes despite untrusted AI — tidyfs

An independent Rust CLI combining deterministic filesystem classification and cleanup eligibility with optional advisory model output. The model cannot authorize mutation, override exclusions, or determine reclaimable bytes. Changes require explicit interactive approval and use reversible quarantine with recovery evidence, rather than permanent deletion.

CLI, recovery model and threat model

Honest partial failure in Git mirroring — Repora

An independent pre-alpha Go CLI that models repository topology, observation, exact ref plans, authorization, stale-head preflight and per-target execution evidence. It intentionally records incomplete mirror convergence instead of presenting independent remote operations as atomic.

Go implementation and operational examples
